07L6 · Terminal
⚙️ Cài đặt

Bước 1: Cài đặt Hermes Agent trên VPS của bạn

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

Trình cài tự lo hết: Python, Node, công cụ phụ. Bạn không cần chuẩn bị gì cả.

08L6 · Terminal

Bước 2: Chọn Provider/Model AI để sử dụng cho Agent

source ~/.bashrc hermes setup # chọn nhà cung cấp + model hermes model # đổi model bất cứ lúc nào
09L7 · Steps dọc
⚙️ Mua API DeepSeek (1/2)

Đăng ký + nạp tiền trước — 2 phút

  • 1Vào platform.deepseek.com → đăng ký (Google/email)
  • 2Mở Top up / Nạp số dư → nạp trước ~$2–5
HÌNH: màn hình trang nạp tiền platform.deepseek.com
10L7 · Steps dọc
⚙️ Mua API DeepSeek (2/2)

Tạo API Key để cấp quyền cho Hermes Agent sử dụng

  • 1Sidebar trái → API keys → Create new API key
  • 2Đặt tên (vd hermes) → copy key dạng sk-… ngay
HÌNH: màn hình tạo API key (che key thật)
11L6 · Terminal
⚙️ Cắm vào Hermes

Cắm DeepSeek vào Hermes: 2 bước là xong

# 1) Dán key vào file ~/.hermes/.env DEEPSEEK_API_KEY=sk-xxxxxxxx
# 2) Chọn DeepSeek làm bộ não hermes model # provider: DeepSeek → model: deepseek-v4-flash

Kiểm tra: gõ hermes → hỏi 1 câu → nó trả lời = đã cắm đúng.

12L7 · Steps dọc
⚙️ Nối Telegram

Bước 3: Setup Telegram làm gateway trò chuyện

  • 1Mở @BotFather → /newbot
  • 2Đặt tên + username kết thúc bot
  • 3Copy token dạng 123456:ABC…
HÌNH: chat với @BotFather tạo bot
13L6 · Terminal
⚙️ Bật cổng Telegram

Khai báo Gateway Telegram

hermes gateway # dán token Telegram khi được hỏi

Nhắn thử cho bot từ điện thoại → Hermes trả lời.
