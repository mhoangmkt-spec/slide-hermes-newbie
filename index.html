Cài đặt · DeepSeek
API 1/2 Mua DeepSeek

Đăng ký + nạp tiền trước — 2 phút

  • 1Vào platform.deepseek.com → đăng ký (Google/email)
  • 2Mở Top up / Nạp số dư → nạp trước ~$2–5
⚠️ DeepSeek trả trước — chưa nạp thì key không chạy.
Cài đặt · DeepSeek
API 2/2 Tạo key

Tạo API Key cấp quyền cho Hermes

  • 1Sidebar trái → API keys → Create new API key
  • 2Đặt tên (vd hermes) → copy key dạng sk-… ngay
⚠️ Key chỉ hiện 1 lần · đừng dán vào chat/công khai.
Cài đặt · DeepSeek
Cắm key DeepSeek → Hermes

Cắm DeepSeek vào Hermes: 2 bước là xong

root@vps: ~
# 1) Dán key vào file ~/.hermes/.env
DEEPSEEK_API_KEY=sk-xxxxxxxx

# 2) Chọn DeepSeek làm bộ não
hermes model     # provider: DeepSeek → deepseek-v4-flash
Kiểm tra: gõ hermes → hỏi 1 câu → Hermes trả lời = đã cắm đúng.
Cài đặt · Telegram
Bước 3 Nối Telegram

Setup Telegram làm gateway trò chuyện

  • 1Mở @BotFather → /newbot
  • 2Đặt tên + username kết thúc bot
  • 3Copy token dạng 123456:ABC…
⚠️ Giữ token bí mật — ai có token là điều khiển được trợ lý.
Cài đặt · Gateway
Bật cổng Gateway Telegram

Khai báo Gateway Telegram

root@vps: ~
hermes gateway     # dán token Telegram khi được hỏi
Nhắn thử cho bot từ điện thoại → Hermes trả lời.
